# Tab Silo — Tab Manager & Suspender

Condense all your tabs into a searchable list, group them into workspaces, and freeze inactive tabs to save RAM.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/mibhobkbekjjdfdlpgcbnbippoigeocc)** · **Website:** [tabsilo.com](https://tabsilo.com/)

## Features
- Condense every open tab into one searchable list
- Group tabs into named workspaces
- Freeze inactive tabs to free up memory and cut clutter

## Tech
Chrome extension (Manifest V3) · JavaScript/TypeScript

## How I built it
I designed and built Tab Silo myself using AI-assisted development (Lovable/Dyad/Cursor), then tested, refined, and published it to the Chrome Web Store. I own the full lifecycle, from design to release.
